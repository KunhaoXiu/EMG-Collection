# 多模态生物力学信号采集系统 (BIMS)

Biomechanical Inertial and Myoelectric System

基于 Web Serial API 的 8 通道肌电 (EMG) + 6 轴惯性 (IMU) 信号实时采集与可视化工具。

## 运行环境

- 浏览器：Chrome 89+ 或 Edge 89+（需支持 Web Serial API 与 File System Access API）
- 记录（边采边写盘，直接落盘）需要安全上下文：通过 `localhost` 或 `https` 访问。直接以 `file://` 打开时 Web Serial 仍可用于实时显示，但无法记录到文件
- 无需安装任何依赖

## 使用方法

1. 用 Chrome 或 Edge 打开 `index.html`（建议经 `localhost`/`https` 访问以启用边采边写盘）
2. 通过 USB 连接唯理 EMG 手环设备
3. 点击 **刷新串口**，在下拉框中选择对应串口
4. 点击 **连接串口**，建立通信（波特率 921600）。连接后即实时显示 8 通道 EMG 波形与 6 轴 IMU 数据；若连接后约 3 秒仍未收到任何数据，调试信息区会提示「设备可能未开机」（串口保持连接，设备开机后会自动开始显示）
5. 点击 **开始记录**，在弹出对话框中选择保存文件；此后数据一边采集一边写入该 CSV 文件（不囤内存、无帧数上限）
6. 采集完成后点击 **停止记录**，写净缓冲并关闭文件

其他操作：
- **暂停绘图**：仅冻结波形/数值显示，后台继续接收；**记录不受影响，继续写盘**
- **清空数据**：只清空当前波形与数值显示（纯画面操作）；不影响接收统计与记录，记录进行中也可随时清屏
- **清日志**：清空「实时接收数据」和「调试信息」两个日志区
- **放大**：点击通道面板右上角 🔍 按钮，放大查看单通道波形
- **主题切换**：点击右上角按钮切换深色/浅色主题
- ESC 键关闭放大模态框

## 界面指标

顶部指标区各项含义：

| 指标 | 含义 |
|------|------|
| EMG / IMU | 各自每秒收到的采样点数（采样率，Hz），分别统计、不叠加 |
| 总帧 | 累计收到的数据包总数（EMG + IMU）|
| 已录 | 已写入 CSV 文件的帧数（仅记录时增长）|
| 错误 | 累计丢包数（含偶发的解析/渲染异常）|
| 缓存 | 待写盘的缓冲行数（边采边写盘时的瞬时积压，正常接近 0）|
| 连接时长 | 串口连接后经过的时间 |
| 记录时长 | 从开始记录到停止记录的时长 |

## 通信协议

设备采用二进制帧协议，每帧固定 29 字节。

### 帧结构

| 偏移 | 长度 | 说明 |
|------|------|------|
| 0-2  | 3    | 帧头 `0xD2 0xD2 0xD2` |
| 3    | 1    | 包类型：`0xAA` = EMG，`0xBB` = IMU |
| 4    | 1    | 序号（0~255 循环递增，AA/BB 共享） |
| 5-28 | 24   | 载荷数据 |

### EMG 包 (0xAA)

载荷包含 8 通道肌电信号，每通道 3 字节：

| 通道 | 偏移 | 格式 |
|------|------|------|
| CH1  | 5-7  | 24bit 有符号整数，大端序 |
| CH2  | 8-10 | 同上 |
| CH3  | 11-13 | 同上 |
| CH4  | 14-16 | 同上 |
| CH5  | 17-19 | 同上 |
| CH6  | 20-22 | 同上 |
| CH7  | 23-25 | 同上 |
| CH8  | 26-28 | 同上 |

- 数值范围：-8388608 ~ 8388607（24bit 有符号）
- 单位：微伏 (μV)

### IMU 包 (0xBB)

载荷包含 3 轴陀螺仪 + 3 轴加速度，各通道 2 字节：

| 通道 | 偏移 | 换算系数 | 单位 |
|------|------|----------|------|
| gyro_x | 7-8  | × 0.0012 | rad/s |
| gyro_y | 9-10 | × 0.0012 | rad/s |
| gyro_z | 11-12 | × 0.0012 | rad/s |
| acc_x | 13-14 | × 0.0005978 | m/s² |
| acc_y | 15-16 | × 0.0005978 | m/s² |
| acc_z | 17-18 | × 0.0005978 | m/s² |

- 所有通道为 16bit 有符号整数，大端序
- 载荷偏移 5-6 为保留字节

### 丢包检测

AA 和 BB 包共享同一个序号字段，每发一个包序号 +1，0xFF 后回绕到 0x00。接收端通过序号连续性检测丢包。

## 记录 CSV 格式

| 列名 | 说明 |
|------|------|
| time | 北京时间（格式 `YYYY-MM-DD-HH-MM-SS`） |
| emg1 ~ emg8 | 8 通道 EMG 值（μV，保留 2 位小数） |
| imu_ax, imu_ay, imu_az | 加速度三轴（m/s²，保留 4 位小数） |
| imu_gx, imu_gy, imu_gz | 陀螺仪三轴（rad/s，保留 4 位小数） |

每个 EMG 包对应一行；IMU 列使用最近一次解析到的 IMU 值。丢包补 `NaN`。
